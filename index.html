Technical Encyclopedia (Basics to Advanced)

                                    
               

1. Azure Infrastructure & Flow

               
Q1: What is Azure Resource Group Flow?

RG stores metadata. If the region chosen for RG is down, management (CRUD) of resources fails. ⚠️ Deletion of RG deletes ALL resources inside permanently.

               
Q2: What is Azure SKU?

Pricing tier identifying performance level. Example: Storage (Standard_LRS vs GRS).

               
Q3: Landing Zone Architecture Flow?

Hub-and-Spoke model. Hub has shared services (Firewall, VPN). Spokes have application workloads. Isolates traffic and centralizes control.

               
Q4: VNet Peering Deep Dive?

Connects VNets via MS backbone. Private traffic. Non-transitive (A↔B, B↔C does not mean A↔C).

               
Q5: What is NSG vs ASG?

NSG is subnet level firewall. ASG is for logical grouping of VMs to apply rules without IP maintenance.

           
                       
               

2. Terraform & State Management

               
Q6: terraform.tfstate Recovery?

JSON source of truth. Recovery: 1. Use terraform import. 2. Remote Backend Versioning. 3. terraform state pull/push.

               
Q7: What is State Locking?

Prevents concurrent changes via Lease ID in Azure Blob. Only one user can 'apply' at a time.

               
Q8: Idempotency in IaC?

Running code multiple times gives the SAME result without creating extra resources.

               
Q9: Terraform Lifecycle (create_before_destroy)?

Ensures zero downtime by creating new resource before killing the old one.

               
Q10: Remote Backend Configuration?

Uses backend "azurerm" to store state in a Blob container for team collaboration.

           
                       
               

3. CI/CD & Pipeline Debugging

               
Q11: Pipeline Failures: Causes & Solutions?

• Expired Secrets: Renew Entra ID secret.
• Offline Agent: Check self-hosted service.
• YAML Syntax: Use ADO Validator.

               
Q12: Self-hosted vs Microsoft Hosted Agents?

Self-hosted gives full VNet/software control. MS Hosted is fresh each run but has limited control.

               
Q13: CI vs CD vs Continuous Deployment?

CI (Build/Test) → CD Delivery (Manual Approval) → Continuous Deployment (Auto to Prod).

               
Q14: Deployment Strategies?

Blue-Green: 100% switch. Canary: 5-10% rollout first.

               
Q15: What are Approval Gates?

Stops deployment until authorized (Manager approval) in ADO environments.

           
                       
               

4. Containers & Orchestration

               
Q16: Dockerfile, Image, Container?

Dockerfile (Recipe) → Image (Snapshot) → Container (Live Process).

               
Q17: How to reduce Docker Image size?

Multi-stage builds and Alpine base images.

               
Q18: What is Kubernetes Pod?

Smallest deployable unit. One or more containers sharing IP/Storage.

               
Q19: K8s Self-Healing?

ReplicaSet detects dead pods and restarts them automatically.

               
Q20: ConfigMap vs Secrets?

ConfigMap (Plain text config). Secrets (Sensitive data - Base64 encoded).

           
                       
               

5. Advanced Scenarios & Git

               
Q21: Production Server Down?

1. Stabilize (Rollback). 2. Logs (RCA). 3. Fix. 4. Prevent.

               
Q22: Git Branching Strategy?

Trunk-based for speed. Git Flow for scheduled releases.

               
Q23: Zero Trust Security?

Never trust, always verify. Every request is authenticated.
