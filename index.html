Interview Encyclopedia (Azure DevOps)

1. Azure Networking & Infrastructure

Q1: What is the Hub-and-Spoke model in Azure?

The Hub is a central VNet containing shared services (Firewall, Gateway). Spokes are VNets that host application workloads, connected to the Hub via VNet Peering for central security control.

Q2: VNet Peering vs VPN Gateway?

VNet Peering connects VNets within the Azure backbone with low latency and high bandwidth. VPN Gateway connects VNets over the public internet (usually for On-Premise to Cloud).

Q3: Difference between NSG and ASG?

NSG (Network Security Group) is a port-level firewall. ASG (Application Security Group) allows you to group VMs logically and apply security rules without managing individual IPs.

2. Infrastructure as Code (Terraform)

Q4: What is Terraform State Locking?

It prevents multiple users from running 'terraform apply' at the same time, avoiding state corruption. In Azure, this is done using a Lease ID on the Blob Storage container.

Q5: What is Idempotency in IaC?

It means that no matter how many times you run the code, the final result will be the same without creating duplicate resources.

Q6: How to handle secrets in Terraform?

Never hardcode secrets. Use Azure Key Vault and fetch them using the 'azurerm_key_vault_secret' data source or environment variables.

3. CI/CD & Pipeline Debugging

Q7: Difference between Microsoft-hosted and Self-hosted Agents?

Microsoft-hosted agents are clean VMs managed by Azure. Self-hosted agents are your own VMs, giving you full control over installed software and network security.

Q8: What are Approval Gates in Azure DevOps?

They stop a deployment to a production environment until a designated person (Manager/Lead) manually approves it after reviewing the build.
