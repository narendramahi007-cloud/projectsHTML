1. What is an Azure Landing Zone?

Answer:

An Azure Landing Zone is a pre-configured, secure, scalable, and governed Azure environment that provides a standardized foundation for deploying workloads.

Core Components

  • Management Groups
  • Subscriptions
  • Hub-Spoke Network
  • Azure Firewall
  • Private DNS
  • ExpressRoute/VPN
  • RBAC
  • Azure Policy
  • Microsoft Defender for Cloud
  • Azure Monitor
  • Key Vault
  • Backup & Disaster Recovery

3. Why do we use Hub-Spoke instead of Flat Network?

Answer

Because it provides

  • Centralized Security
  • Traffic Inspection
  • Reduced Cost
  • Easy Governance
  • Scalable Architecture
  • Network Isolation

Merge

  • Cleaner history
  • Rewrites commits
  • Used before PR

13. Security Scans in DevSecOps Pipeline

Order matters:

  1. GitLeaks / TruffleHog – Secret scanning
  2. TFLint – Terraform linting
  3. Checkov – IaC policy validation
  4. tfsec – Terraform security
  5. SonarQube – Code quality & vulnerabilities
  6. Snyk / Black Duck – Dependency scanning
  7. Trivy – Container image scanning
  8. Microsoft Defender for Cloud – Runtime security
  9. Qualys / Tenable – VM vulnerability assessment
